- Strict TypeScript and ESLint pass. 33 Vitest unit/integration tests pass, including tenant constraints, auth, idempotent care, transfers, token retirement, private media, analysis lifecycle/leases, history pagination, equal-weight fleet aggregation, plant/workspace-scoped job claims, PKCE/state/nonce/JWT verification, DPAPI credential round trip and chunked SSE completion checks.

These are local tests. Fixture-provider success is not subscribed inference proof.
- Production browser checks created an isolated **NABAT Pilot Verification** workspace and a clearly named QA plant. Registration, onboarding, species/location selection, stable identity creation, one-tap watering, real private photo upload and queued-worker status were observed on the canonical domain. After reload, care and photo history persist. Credentials remain in ignored local data, not this ledger.
- Production HTTP checks: homepage/health/manifest/NFC return 200; unauthorized plant API returns 401; shared demo login returns 404; signed private media returns 200 and unsigned access returns 403; real tag SVG returns 200; secret-authenticated cron returns 200 with zero inline analyses in external-runtime mode. Operational location, caretaker, photo/note and health fields are absent from the public NFC projection. See `production-check.json`.
- Neon has all seven migrations and seven catalog species. The cloud connection was tested with encrypted TLS and an authorized certificate. Private Blob write/read matched exact bytes; unauthenticated object URL returned 403 and the temporary verification object was removed.
- The initial Gateway adapter returned valid structured vision using its accessible GPT-4.1 Mini model (`gateway-probe.json`). The input was an AI-generated botanical asset. This was an integration check, not biological model evaluation. Gateway was subsequently disabled to honor the user's subscription-only requirement.
- Production now uses `AI_PROVIDER=chatgpt-subscription`, `ANALYSIS_RUNTIME=external`. Jobs remain queued with zero attempts until the scoped local worker runs. No API-key, paid Gateway or model fallback is used in this mode.
- Actual Business Premium OAuth permission, account-specific GPT-6.1 Sol availability and subscribed image inference are **pending human authorization**. The official authorization flow reached the selected Business workspace's consent screen in the user's Edge browser. Written adapters, tests and an open consent screen do not establish completed authorization.

## Remaining boundaries

Physical NFC encoding/tapping, phone camera permission/actual camera hardware, physical PWA install, calibrated botanical accuracy, throughput/load and Docker/S3 alternatives were not exercised. A local subscription worker needs the computer running, an eligible authorized account and an explicitly selected NABAT workspace. The preview's commercial/cloud eligibility is not inferred from local registration support. Email verification/recovery/delivery and billing checkout remain documented next-stage integrations.
