# NABAT 1.1 verification

Accepted software channel: 1.1.0 pilot, checked 2026-10-04 (Asia/Dubai). Physical NFC equipment and signing certificates were explicitly deferred by the user.

## Executed checks

- TypeScript typecheck, ESLint, generated-contract drift check and production build passed. Six Vitest suites passed **67 tests**. They cover tenant/capability denial, actor-bound capture, idempotency, stale atomic batches, alert/session outcomes, Viewer restrictions, ownership transfer cleanup, private maps/imports/QR, lifecycle rates and older observations not replacing newer scores. A 1,000-identity synthetic case verifies separate pages and global metrics; it is not a throughput or memory benchmark.
- Native x64 builds passed with zero warnings/errors. The final self-contained publish initially omitted the app resource index/XBF outputs; an explicit MSBuild publish target repaired that omission. The **published EXE**, not only the build-folder EXE, subsequently passed rendering, restart and cloud acknowledgement. ZIP/MSIX inspection verifies those resources and rejects private/test-state files. **25 C# tests** passed for transport, scope, restart storage, retry/conflict handling, DPAPI, cache/URI validation, NDEF, pixel fit/premultiplied differences and elapsed-time coordinates. ARM64 publish and MSIX construction passed; ARM64 execution was not tested.
- **Eight Playwright end-to-end checks passed** against the isolated port-3001 server: 1.0 registration/plant/tag/mobile care/photo/privacy/replacement flows, automated WCAG checks and the new 390px offline-care → replay → session visit → completed work → native contract flow. The development vision fixture is explicitly synthetic.
- IAB was used for actual Today filtering, care logging, maintenance completion and reload persistence. Desktop 1440×1000 and mobile 390×844 captures are in `release-1.1-published/`. Its error log query returned no entries. Playwright's offline emulation was used because IAB has no network-offline switch; it did not replace the IAB interaction/visual review.
- The running WinUI application captured its own XAML tree through RenderTargetBitmap. Native computer-use APIs were disabled, so no desktop/compositor automation was used. `release-1.1-published/native-live-flow.json` records local write, reopened-store recovery, acknowledgement, exact-once replay and a completed visit. `process-restart-proof.json` comes from **two actual processes** and confirms DPAPI session, workspace, Plants navigation, child profile context and pending care recovery/sync.
- `nfc-simulation.json` confirms encoded/read-back bytes and server audit, with `physicalTagWritten=false`. Physical compatibility, UID/RF behaviour and phone taps remain untested.

## Remaining external acceptance boundaries

Unsigned MSIX is a valid package, not trusted installation. Physical NFC readers/tags, physical print/PDF-device output, installed OS protocol activation, trusted upgrades/uninstall, actual notification delivery, multi-monitor/long-duration operation, OS-wide high contrast and maximum text scale are not proven by compilation or XAML captures. There is no automated update service in the pilot. Recent native cache/outbox works offline; arbitrary uncached originals and a fresh offline private-PWA launch are not release claims. Some extended metadata and provider/user text are not fully translated. These boundaries remain explicit in the release guide.
